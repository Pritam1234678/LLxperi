02 — Java String Basics

String Immutability

Java mein String immutable hai — har modification new object banata hai. Loop mein String concatenation O(n²) ho jaata hai. Isliye StringBuilder use karo!

// Bad — O(n²)
String result = "";
for (char c : arr) result += c;

// Good — O(n)
StringBuilder sb = new StringBuilder();
for (char c : arr) sb.append(c);
String result = sb.toString();

s.length()          // length
s.charAt(i)         // char at index
s.toCharArray()     // char[] — for loops

s.substring(i, j)   // [i, j)

s.equalsIgnoreCase(t)
s.toLowerCase()
s.toUpperCase()

s.split(" ")        // String[]

char ↔ int Tricks

// char to int (frequency index)
int idx = c - 'a';   // 0–25

// int to char

// Check if lowercase

// Frequency array — faster than HashMap

01
Reverse a String Easy Xperi Asked

Ek character array s[] ko in-place reverse karo. Extra array use mat karo. Input: ['h','e','l','l','o'] → Output: ['o','l','l','e','h']

Approach
Two Pointers — left = 0, right = n-1. Swap karo aur dono ko andar laao jab tak milte nahi.
void reverseString(char[] s) {
    int left = 0, right = s.length - 1;
    while (left < right) {
        char tmp = s[left];
        s[left]  = s[right];
        s[right] = tmp;
        left++;
        right--;
    }
}
Time O(n)
Space O(1)
Xperi ka exact question: "Reverse the String in O(1) space." Yahi solution hai — do not use new array ya StringBuilder!
02
Valid Palindrome Easy

Ek string palindrome hai ya nahi check karo — sirf alphanumeric characters consider karo, case-insensitive.

Approach
Two Pointers — non-alphanumeric skip karo. Left aur right ka lowercase compare karo.
boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        // skip non-alphanumeric
        while (left < right && !Character.isLetterOrDigit(s.charAt(left)))
            left++;
        while (left < right && !Character.isLetterOrDigit(s.charAt(right)))
            right--;
        if (Character.toLowerCase(s.charAt(left)) !=
            Character.toLowerCase(s.charAt(right)))
            return false;
        left++; right--;
    }
    return true;
}
Time O(n)
Space O(1)
03
Valid Anagram Easy

Do strings s aur t anagrams hain ya nahi check karo (same characters, same frequencies).

Approach
Frequency array [26] — s ke chars increment karo, t ke chars decrement karo. Agar sab zero hain = anagram.
boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] freq = new int[26];
    for (int i = 0; i < s.length(); i++) {
        freq[s.charAt(i) - 'a']++;
        freq[t.charAt(i) - 'a']--;
    }
    for (int f : freq)
        if (f != 0) return false;
    return true;
}
Time O(n)
Space O(1) — fixed 26
Frequency array [26] HashMap se faster hai for lowercase-only strings — interviewer ko yeh bolo!
04
First Unique Character Easy

String mein pehla non-repeating character ka index nikalo. Nahi mila toh -1 return karo.

Approach
Two-pass — pehle frequency count karo, phir left se scan karo pehla char jiska freq = 1 milega.
int firstUniqChar(String s) {
    int[] freq = new int[26];
    for (char c : s.toCharArray()) freq[c - 'a']++;
    for (int i = 0; i < s.length(); i++)
        if (freq[s.charAt(i) - 'a'] == 1) return i;
    return -1;
}
Time O(n)
Space O(1)
05
Reverse Words in a String Easy

String ke words ko reverse order mein return karo. Extra spaces remove karo.

Approach
Split by spaces → filter empty → reverse array → join. Ya two-pointer in-place approach.
String reverseWords(String s) {
    String[] words = s.trim().split("\\s+"); // \\s+ = multiple spaces
    int left = 0, right = words.length - 1;
    while (left < right) {
        String tmp = words[left];
        words[left++] = words[right];
        words[right--] = tmp;
    }
    return String.join(" ", words);
}
Time O(n)
Space O(n)

Remove Adjacent Duplicates Medium Xperi Asked

String mein adjacent duplicate characters remove karo. Example: "akcddcef" → "akef" (dd remove → "akccef" → cc remove → "akef")

Approach
Stack — har character peek se compare karo. Same hai toh pop karo (cancel). Different hai toh push karo. End mein stack se result banao.
String removeDuplicates(String s) {
    Stack<Character> stack = new Stack<>();
    for (char c : s.toCharArray()) {
        if (!stack.isEmpty() && stack.peek() == c)
            stack.pop();   // adjacent match → cancel!
        else
            stack.push(c);
    }
    StringBuilder sb = new StringBuilder();
    for (char c : stack) sb.append(c);
    return sb.toString();
}
// "akcddcef" → stack: a,k,c,d → d cancels → k,c,c → c cancels → a,k → e,f
// Result: "akef" ✓
Time O(n)
Space O(n)
Exactly Xperi ka question — "akcddcef" — yeh example bolo! Stack ka LIFO nature adjacent cancellation ke liye perfect hai.
07
Longest Substring Without Repeating Characters Medium

String mein longest substring without repeating characters ki length nikalo.

Approach
Sliding Window + HashMap — right expand karo, jab duplicate mile left ko us character ke baad shrink karo.
int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();
    int maxLen = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c))
            left = Math.max(left, map.get(c) + 1); // shrink
        map.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
// "abcabcbb" → 3 ("abc")
Time O(n)
Space O(k) — k = charset size
left = Math.max(left, ...) — yeh line important hai. Left ko kabhi peeche mat jaane do!
08
Valid Parentheses Medium

String mein brackets balanced hain ya nahi check karo — '(', ')', '{', '}', '[', ']'

Approach
Stack — opening bracket push karo. Closing bracket pe: stack empty hai ya top match nahi karta toh false. End mein stack empty hona chahiye.
boolean isValid(String s) {
    Stack<Character> stack = new Stack<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '{' || c == '[')
            stack.push(c);
        else {
            if (stack.isEmpty()) return false;
            char top = stack.pop();
            if (c == ')' && top != '(') return false;
            if (c == '}' && top != '{') return false;
            if (c == ']' && top != '[') return false;
        }
    }
    return stack.isEmpty();
}
Time O(n)
Space O(n)
09
Group Anagrams Medium

Strings ki list mein anagrams group karo. ["eat","tea","tan","ate","nat","bat"] → [["bat"],["nat","tan"],["ate","eat","tea"]]

Approach
HashMap with sorted string as key — anagrams ka sorted form same hoga. Map mein group karte jao.
List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] ch = s.toCharArray();
        Arrays.sort(ch);
        String key = new String(ch); // sorted key
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
Time O(n·k log k)
Space O(n·k)
10
Longest Palindromic Substring Medium

String mein longest palindromic substring nikalo. "babad" → "bab" ya "aba".

Approach
Expand Around Center — har character aur har pair ko center manke expand karo. Odd (single center) aur Even (pair) dono cases handle karo.
String longestPalindrome(String s) {
    int start = 0, maxLen = 1;
    for (int i = 0; i < s.length(); i++) {
        // Odd length palindrome (single center)
        int len1 = expand(s, i, i);
        // Even length palindrome (pair center)
        int len2 = expand(s, i, i + 1);
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = i - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        l--; r++;
    }
    return r - l - 1; // length of palindrome
}
Time O(n²)
Space O(1)
Odd vs Even dono cases alag handle karo — common mistake ek hi bhool jaana hai!
11
String Compression Medium

Character array compress karo in-place — "aaabbbcc" → "a3b3c2". Agar single char toh count mat likho.

Approach
Two pointer — read pointer se scan karo, write pointer se result likho. Consecutive same chars count karo.
int compress(char[] chars) {
    int write = 0, i = 0;
    while (i < chars.length) {
        char cur = chars[i];
        int count = 0;
        while (i < chars.length && chars[i] == cur) { i++; count++; }
        chars[write++] = cur;
        if (count > 1) {
            for (char c : String.valueOf(count).toCharArray())
                chars[write++] = c;
        }
    }
    return write;
}
Time O(n)
Space O(1)
12
Minimum Window Substring Medium

s mein t ke sab characters contain karne wala smallest substring nikalo.

Approach
Sliding Window + two frequency maps — window expand karo jab tak sab chars cover ho jayein, phir shrink karo minimum window ke liye.
String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);
    int left=0, minL=0, minLen=Integer.MAX_VALUE, formed=0;
    int required = need.size();
    Map<Character, Integer> win = new HashMap<>();
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        win.merge(c, 1, Integer::sum);
        if (need.containsKey(c) && win.get(c).equals(need.get(c))) formed++;
        while (formed == required) {
            if (right - left + 1 < minLen) { minLen = right-left+1; minL = left; }
            char lc = s.charAt(left++);
            win.merge(lc, -1, Integer::sum);
            if (need.containsKey(lc) && win.get(lc) < need.get(lc)) formed--;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(minL, minL+minLen);
}
Time O(|s| + |t|)
Space O(|s| + |t|)

Min Deletions to Make Palindrome Hard Xperi Asked

Ek string se minimum characters delete karo taaki palindrome ban jaaye. s = "agbcba" → 1 (delete 'g' → "abcba")

Approach
LCS Pattern — min deletions = len(s) - LCS(s, reverse(s)). LCS (Longest Common Subsequence) nikalo s aur uske reverse ke beech.
int minDeletions(String s) {
    String rev = new StringBuilder(s).reverse().toString();
    int n = s.length();
    // DP for LCS between s and its reverse
    int[][] dp = new int[n+1][n+1];
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (s.charAt(i-1) == rev.charAt(j-1))
                dp[i][j] = 1 + dp[i-1][j-1];
            else
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
        }
    }
    int lcs = dp[n][n]; // longest palindromic subsequence
    return n - lcs;    // deletions = total - lps
}
// "agbcba": LPS = "abcba" (len 5), deletions = 6 - 5 = 1 ✓
Time O(n²)
Space O(n²)
Yeh EXACTLY Xperi ka question hai — s = "agbcba". LCS insight yahan key hai: LCS(s, reverse(s)) = Longest Palindromic Subsequence. Yeh insight bologe toh interviewer impressed hoga!
14
Decode Ways Hard

'A'=1 ... 'Z'=26 encoding hai. Digit string ko kitne taaron mein decode kar sakte hain? "226" → 3 ("BZ"/"VF"/"BBF")

Approach
1D DP — dp[i] = string[0..i-1] ke kitne decode ways hain. Har position pe single digit aur two digit dono check karo.
int numDecodings(String s) {
    int n = s.length();
    if (s.charAt(0) == '0') return 0;
    int[] dp = new int[n + 1];
    dp[0] = 1; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        int one = s.charAt(i-1) - '0';
        int two = Integer.parseInt(s.substring(i-2, i));
        if (one >= 1) dp[i] += dp[i-1]; // valid single digit
        if (two >= 10 && two <= 26) dp[i] += dp[i-2]; // valid two digit
    }
    return dp[n];
}
Time O(n)
Space O(n)
15
Longest Repeating Character Replacement Hard

String mein at most k characters replace karke sabse lamba same-character substring nikalo. "AABABBA", k=1 → 4

Approach
Sliding Window — window valid hai agar (window size - max freq char count) ≤ k. Invalid hone pe left shrink karo.
int characterReplacement(String s, int k) {
    int[] freq = new int[26];
    int left = 0, maxFreq = 0, maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        freq[s.charAt(right) - 'A']++;
        maxFreq = Math.max(maxFreq, freq[s.charAt(right) - 'A']);
        // window invalid: chars to replace > k
        if (right - left + 1 - maxFreq > k) {
            freq[s.charAt(left) - 'A']--;
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
Time O(n)
Space O(1)
Key insight: (window_size - max_freq) = minimum replacements needed. Agar yeh > k hai toh window shrink karo.
